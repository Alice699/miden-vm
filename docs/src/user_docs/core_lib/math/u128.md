# u128

A `u128` value is represented on the stack as four 32-bit limbs in little-endian order, with the least significant limb on top:

```
Stack (top → bottom): [a0, a1, a2, a3]
  where a = a0 + a1·2^32 + a2·2^64 + a3·2^96
```

| Procedure | Description |
| ----------- | ------------- |
| overflowing_add | Performs addition of two unsigned 128-bit integers preserving the overflow. The input values are assumed to be represented using 32-bit limbs, but this is not checked. The stack transition looks as follows: `[b0, b1, b2, b3, a0, a1, a2, a3, ...] -> [overflow, c0, c1, c2, c3, ...]`, where `c = (a + b) % 2^128`. |
| widening_add | Performs addition of two unsigned 128-bit integers preserving the overflow with sum on top.
